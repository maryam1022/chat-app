# 💬 Chat App

A web-based chat application designed to provide users with an interactive interface for sending and managing messages.

## ✨ Features

* Clean and user-friendly chat interface
* Interactive messaging interface
* Responsive design
* Dynamic user interactions
* Organized chat layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📱 Responsive Design

The application is designed to provide a good user experience across:

* Desktop
* Tablet
* Mobile
